# 💰 BudgetBuddy

A simple income and expense tracker. Log transactions and see where your money goes.

## Main Features
- Dashboard with balance, income, expenses and transaction count
- Spending-by-category breakdown with bars
- Recent transactions list
- Add, edit and delete transactions (income or expense, with category and date)
- Search, and filter by type or category
- Data saved in your browser with LocalStorage
- Responsive design with modal forms and toast messages

## Technologies
HTML5, CSS3, Vanilla JavaScript, LocalStorage

## How to Run
Open `index.html` in any modern browser. No install or server needed.
